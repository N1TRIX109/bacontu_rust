# Fidelity Hotel — порт лобби и Waybackyard на Rust

Порт части GameMaker-проекта `whatsshakinbacon` (лобби и уровень «задний двор» / `wayback_*`)
на Rust + [macroquad](https://macroquad.rs).

## Запуск

```bash
# 1. (один раз) сконвертировать ресурсы из GameMaker-проекта — готовый результат уже лежит в assets/
python3 tools/convert.py <путь/к/whatsshakinbacon-main> assets

# 2. запуск (из корня проекта, чтобы нашлась папка assets/)
cargo run --release
```

Управление (в игре подсказка сверху): **V — ноуклип** (свободный полёт сквозь стены, Shift — быстрее; выключить можно только вне стены), ←→ / A D — ходьба, **Z / Space** — прыжок, **Shift / X** — бег (mach), ↓ — присесть,
↑ — войти в дверь или ворота уровня, **R** — рестарт, **F3** — отладка.

## Что НЕ портировано (нужно доделывать)

- **Полная звуковая система FMOD** (параметры событий, `state` у музыки Mangrove, звуки врагов, UI, ранги, комбо).
  Вместо банков используются готовые файлы: см. раздел «Звук».
- Состояния игрока, которых нет в Waybackyard: taunt, parry, ski, snowball, skateboard, surfing, gunk, slip, diveboard. Hauling упрощён
  (без swingading-вращения и части финишеров); персонаж - Mildred (buzzsaw на вершине стены).
- В Rock Bottom нет pizza time (в оригинале в `city_*` нет монолита), `obj_partyportal` (лэп) и вентилятор из `rock_*`.
- Указатели побега (obj_escape_pointer), Pizzaface, лэп-портал (obj_partyportal), комбо/ранги, титлкарды, сохранения, pause-меню, онлайн (`obj_server`), палитры (`shd_pal_swapper`).
- Спрайты `obj_*`, которые рисуются шейдерами/из кода (`create_gate_layer` у ворот и т.п.).
- Ворота ведут в `wayback_1` напрямую (без титлкарда); ворота в другие уровни (`city_*`, `tutorial`) показывают подсказку.

## Звук

Звуки из `sfxs.zip` отобраны и сконвертированы в `.ogg` скриптом `tools/convert_audio.py` (таблица «событие → файл» в начале скрипта).
Музыка: лобби — `Dining Hall and Lucid Dreams`, Waybackyard — `Through Troubled Waters` (+ дождь/птицы как атмосфера),
секреты — `waybackSecret`. Эффекты: прыжок, шаги, петли бега mach2/mach3/maxspeed, удары о стену, разворот и торможение,
дверь, разрушение блока, коллекты. **Соответствие файлов событиям — моя догадка по названиям и длительности**;
если какой-то звук не тот, поменяйте имя файла в таблице и запустите скрипт заново (нужен `ffmpeg`).
На Linux для звука нужен пакет `libasound2-dev`.

## Туториал

Ворота в лобби (`hotel_receptionentrance`) ведут в `tutorial_1`. Подсказки Flo берутся из оригинального creation code комнат;
обозначения кнопок `[J]`, `[D]`, `[U]`... заменены на кнопки порта. Часть подсказок описывает механики, которых в порте ещё нет
(superjump, buzzsaw, grab) — они просто показываются текстом. Монолит в `tutorial_7` запускает pizza time (3:00), выход — `obj_exitgate` в `tutorial_1`;
после выхода туториал считается пройденным и `obj_tutorialBlock` в лобби исчезает.

## Структура

```
tools/convert.py   .yy комнат/спрайтов/тайлсетов -> JSON + PNG (assets/)
src/assets.rs      загрузка JSON/текстур, отрисовка спрайтов и тайлов
src/world.rs       Room: блоки столкновений, двери, холлвеи, подборы, декор
src/player.rs      физика и состояния игрока (порт GML)
src/audio.rs       загрузка и воспроизведение звука
src/hud.rs         телевизор и комбо (порт obj_hud / obj_comboTitle)
src/menu.rs        пауза, главное меню, настройки
src/save.rs        сохранения (ini) и ранги
src/main.rs        цикл 60 Гц, переходы между комнатами, камера, отрисовка
```

## Важно

Код написан без доступа к компилятору Rust (в среде, где делался порт, не было `cargo`/сети),
поэтому **проект ни разу не собирался**. Возможны мелкие ошибки компиляции — сообщения `cargo build`
пришлите, поправлю. Геометрия комнат и точки спавна проверены скриптом на данных (игрок не появляется внутри стен).

Ассеты (`assets/`) — это перекодированные ресурсы оригинальной игры: используйте их только в рамках
имеющихся у вас прав на проект.
